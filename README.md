# AI Disease Prediction System

A full-stack project using Flask + Machine Learning to predict Heart Disease and Diabetes risk.

## Features
- Risk Prediction
- Health Score
- AI Explanation
- Diet & Exercise Recommendations
- Chart Visualization

## Run Project

Install:
python3 -m pip install -r requirements.txt

Run backend:
PORT=5001 python3 backend/app.py

Open frontend:
frontend/index.html
